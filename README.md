# TaskBuddy 📝

TaskBuddy is a simple **Task Management Web Application** that helps users create and manage their daily tasks.

This is my **2nd project as part of the Thiranex internship**, where I worked on understanding and building a full-stack web application.

## Features

* User Sign Up and Login
* Add new tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* Search for tasks
* Filter tasks by:
  * All
  * Pending
  * Completed
* Add task priority:
  * Low
  * Medium
  * High
* Add task due dates
* Light and Dark Mode
* Responsive design for mobile and desktop

## Technologies Used

* **HTML** – For creating the webpage
* **CSS** – For styling and responsive design
* **JavaScript** – For adding functionality
* **Node.js** – For the backend
* **Express.js** – For creating the API
* **SQLite** – For storing users and tasks
* **JWT** – For user authentication
* **bcryptjs** – For password security
